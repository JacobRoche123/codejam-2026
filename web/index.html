How this is measured

          
    
            
  • Cost and tokens: real token counts returned by the Claude API × Anthropic's published prices. ThinkLess's total includes its triage (and any clarifying round).
    • 
            
  • Quality:  grades both answers without knowing which is which, twice with the order swapped; scores are averaged.
    • 
            
  • Energy: not shown. Anthropic does not publish energy per request; fewer tokens on a smaller model means less compute, but we do not invent watt-hours.
    • 
            
  • One prompt is one sample: answers vary between runs. The Benchmark tab averages 20 tasks.

Why cost measures compute

        
Price per token follows model size: an output token from Haiku 5.5 costs 40 times less than one from Opus 5.5. Fewer dollars means less compute, so less energy, at equal quality.
